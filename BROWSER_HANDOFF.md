# Browser execution removed

Browser/computer control was removed on November 4 at the user's request.
There is no worker, execution endpoint, browser setup, or browser dependency.
Use `uv run second-brain` for the app. Ask Muse and Hand off use persistent task
chat, with native Meta web search when useful.

Historical browser_runs rows, migrations, screenshots and downloads remain intact
on disk/database. There is no current execution or artifact-serving interface.
No data purge or schema downgrade is part of this removal.
